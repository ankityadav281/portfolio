Paramarsh — Smart Medical Consultation Platform

REACT 19 · NODE.JS · EXPRESS 5 · MYSQL · xAI GROK API · BROADCASTCHANNEL

Paramarsh is a full-stack digital healthcare and medical consultation web application engineered to bridge patients with verified medical specialists. It delivers an AI-guided clinical triage system alongside low-latency, real-time doctor–patient consultation rooms.

🌟 Architectural & Technical Highlights

  • AI Clinical Assistant (xAI Grok + Intelligent Fallback): Integrated with xAI Grok API for contextual symptom guidance, equipped with a dual-inference path that seamlessly falls back to a deterministic local rule engine if external APIs are unreachable.
  • Doctor Directory & Specialty Discovery: Advanced search with multi-parameter filtering by specialization, years of experience, consultation fee, and real-time availability status.
  • Real-Time Doctor–Patient Chat: Synchronized two-way communication across browser tabs leveraging native BroadcastChannel and StorageEvent listeners without requiring external websocket infrastructure.
  • Resilient MySQL Data Architecture: Built on MySQL 8+ using mysql2 connection pooling for user and consultation entities, with an automatic in-memory cache failover layer ensuring 100% uptime during transient database disconnects.
  • Role-Based Access Control (RBAC): Dual authentication lifecycle for Patients and Medical Doctors with bcryptjs salted password hashing and stateless JSON Web Tokens (JWT).
  • Modern Medical UI: Crafted with React 19, React Router 7, Vite, Lucide React, and medical design tokens.
Technologies: React 19, React Router 7, Vite, Node.js, Express.js 5, MySQL, RESTful APIs, JWT, bcryptjs, xAI Grok, BroadcastChannel, Lucide React.

CampusCart — University Marketplace Web Application

REACT 18 · TAILWIND CSS v4 · DJANGO 6.1 · DRF · SQLITE ATOMIC TRANSACTIONS

CampusCart is a production-grade, multi-vendor university e-commerce marketplace web app designed for college campuses, faculty, hostelers, and campus merchants. It unifies campus canteens, stationery stores, photocopy centers, and marts into a frictionless digital platform.

🌟 Architectural & Technical Highlights

  • Atomic Multi-Order Checkout: Multi-shop unified cart allows students to order from multiple stores at once. The backend executes inside an atomic database transaction (transaction.atomic() + select_for_update()) generating 1 Parent OrderGroup and N independent Vendor Orders with strict inventory locking.
  • Scheduled Campus Pickup Slot Reservations: Students select designated counter pickup slots (e.g., 10:00 AM – 10:15 AM Recess Break) to completely eliminate rush-hour lines between academic lectures.
  • Merchant Onboarding & Auto-Handle Derivation: Dedicated seller registration with real-time lowercase username handle derivation (e.g., "Lovely Bake Studio" ➔ lovelybakestudio) and strict input sanitization.
  • Shop Owner Dashboard (/shop-dashboard): Strict RBAC multi-tenancy where vendors manage product CRUD, stock thresholds with 1-click restock, live revenue charts, and a strict 5-stage fulfillment state machine (Pending ➔ Accepted ➔ Preparing ➔ Ready for Pickup ➔ Completed).
  • Platform Admin Governance (/admin-dashboard): Platform-wide order oversight, merchant application approval/suspension queues, and 55+ campus store category sub-types.
  • Automated Test Suite: Comprehensive unit and integration test suite covering JWT authentication, atomic cart splitting, inventory deduction, and cancellation stock restoration.
Technologies: React 18, Vite 8, Tailwind CSS v4, Django 6.1, Django REST Framework, SQLite3, SimpleJWT, Axios Interceptors, Context API.

ANDROID · CLEAN ARCHITECTURE

Aasha — Empowering Community Health Workers (ASHA)

KOTLIN · JETPACK COMPOSE · ROOM SQLITE · FIREBASE · WORKMANAGER · HILT

Aasha is a specialized Android application designed to digitalize and streamline the field workflows of Accredited Social Health Activists (ASHA) across India. Built for extreme resilience in low-connectivity rural environments.

🌟 Architectural & Technical Highlights

  • Offline-First Architecture: Room (SQLite) database serves as the single source of truth with reactive Kotlin StateFlow. Field records are persisted locally first and synchronized with Firebase Firestore when network connectivity is established.
  • Comprehensive Patient Lifecycle & Deduplication: Smart patient registration with integrated fuzzy duplicate detection preventing redundant records, home visit logs, and vaccination tracking with automated booster scheduling.
  • Dual-Layer Security: Cloud authentication via Firebase Auth paired with a 4-digit hardware-encrypted MPIN, allowing workers to quickly unlock the app in the field without internet access.
  • Proactive Health Reminders: Background workers using Android WorkManager trigger automated local notifications for upcoming immunizations and prenatal checkup appointments.
  • Multilingual Localization: Localized in Hindi, Bengali, and Marathi, with cultural nuances and terminology tailored specifically for grassroots health workers.
  • Clean Architecture & MVVM: Clean separation across data, domain, UI, and viewmodel layers, with Hilt dependency injection and structured Kotlin Coroutines.
Technologies: Kotlin, Jetpack Compose, Room DB, Firebase (Firestore & Auth), Android WorkManager, Hilt (Dagger), Coroutines, StateFlow, Compose Navigation.
