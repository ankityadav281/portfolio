01 / HEALTHCARE ARCHITECTURE

Paramarsh – AI Medical Consultation Platform

React 19 · Node.js · Express 5 · MySQL 8+ · xAI Grok API · BroadcastChannel · JWT

A digital healthcare consultation web platform connecting patients with verified medical specialists. Delivers an AI-guided clinical triage system alongside low-latency, real-time doctor–patient consultation rooms.

Technical Specifications & Decisions

  • Integrated with xAI Grok API for clinical symptom guidance, featuring an intelligent rule-based local fallback across 2 inference paths for maximum offline/disconnect reliability.
  • Doctor specialty discovery with multi-parameter filtering by medical domain, experience, consultation fee, and live availability status.
  • Cross-tab real-time consultation synchronization leveraging native browser BroadcastChannel and StorageEvent APIs without external websocket overhead.
  • Resilient MySQL 8+ data layer using mysql2 connection pooling and an automatic in-memory failover cache ensuring 100% uptime during database disconnects.
  • Role-based access control with salted bcryptjs password hashing and stateless JWT session handling for Patients and Doctors.

02 / E-COMMERCE & TRANSACTIONS

CampusCart – University Multi-Vendor Marketplace

React 18 · Vite · Tailwind CSS v4 · Django 6.1 · Django REST Framework · SQLite3

Production-grade multi-vendor university marketplace web application designed for campus stores, faculty, students, and hostelers to eliminate break-time counter queues.

Technical Specifications & Decisions

  • Atomic multi-vendor cart checkout executing within atomic database transactions (transaction.atomic + select_for_update) generating 1 Parent OrderGroup and N independent Vendor Orders with strict inventory locking.
  • Scheduled recess break pickup slot reservation (e.g. 10:00 AM – 10:15 AM) eliminating rush-hour canteen queues between lectures.
  • Merchant onboarding with real-time lowercase username handle derivation (e.g., "Campus Bakery" ➔ campusbakery) and strict input sanitization.
  • Multi-tenant shopkeeper dashboard with live KPIs, inventory thresholds with 1-click restock, and a 5-stage fulfillment state machine.
  • Automated test suite covering JWT authentication, atomic cart splitting, inventory deduction, and cancellation stock restoration.

04 / MOBILE & RESILIENCE

Aasha – Empowering Community Health Workers (ASHA)

Kotlin · Jetpack Compose · Room SQLite · Firebase · WorkManager · Hilt · StateFlow

Specialized Android application built for Accredited Social Health Activists (ASHA) in rural India, engineered for extreme reliability in low-connectivity rural environments.

Technical Specifications & Decisions

  • Offline-first architecture with Room (SQLite) database and reactive Kotlin StateFlow as the single source of truth, synchronizing with Firebase Firestore when network connectivity is established.
  • Patient lifecycle onboarding with fuzzy duplicate detection preventing redundant records, home visit logs, and vaccination booster dose tracking.
  • Dual-layer security with Firebase Auth paired with a hardware-encrypted 4-digit MPIN for rapid field unlocking without internet access.
  • Proactive health monitoring with Android WorkManager background workers triggering automated local notifications for upcoming vaccinations.
  • Multilingual localization in Hindi, Bengali, and Marathi with cultural terminology tailored for field health workers.
